# Drink sets catalogue

Same format as teas.md. Edit a row, then "apply sets.md" to regenerate sets.html;
on push, sets.md is also mirrored to the Telegram channel (posted after the teas).

- **№** — position in the list
- **Name** — set name
- **Description** — short line under the name
- **Tags** — pipe-separated; first tag is the index category (keep "DRINK SETS")
- **Photo** — filename inside `webtea/photos/` (or blank for the kanji placeholder)
- **Price** — free-form, `/`-separated for multiple lines
